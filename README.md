# दैनिक मान्यवर (Dainik Manyawar) - Full-Stack Hindi News Portal & E-Paper CMS

दैनिक मान्यवर का आधिकारिक आधुनिक हिंदी समाचार वेब पोर्टल और समर्पित ई-पेपर (E-Paper) प्रबंधन प्लेटफॉर्म।

---

## 🌟 प्रमुख विशेषताएं (Key Features)

### 1. आधुनिक डिजिटल समाचार पोर्टल (News Web Portal)
* **होमपेज (`index.html`)**: ब्रेकिंग न्यूज़ टिकर, मुख्य हेडलाइन्स, श्रेणीवार समाचार, ट्रेंडिंग न्यूज़, और डार्क/लाइट थीम सपोर्ट।
* **श्रेणी पृष्ठ (`category.html`)**: राजनीति, देश, डिफेंस, शिक्षा, अर्थजगत, हेल्थ, विदेश, मत-विमत, समाज-संस्कृति आदि।
* **विस्तृत समाचार पृष्ठ (`article.html`)**: सम्पूर्ण समाचार विवरण, फोटो, सोशल शेयरिंग (व्हाट्सएप/फेसबुक), संबंधित खबरें, डायनामिक व्यू काउंटर और टिप्पणी प्रणाली।
* **टाइमलाइन फीड (`feed.html`)**: रियल-टाइम क्रोनोलॉजिकल समाचार अपडेट्स।

### 2. समर्पित ई-पेपर रीडर (`epaper.html`)
* **दैनिक ई-पेपर व्यूअर**: 8 से 10 पन्नों के पूरे ब्रॉडशीट अखबार का डिजिटल संस्करण।
* **ज़ूम व पैन टूल्स**: 50% से 300% ज़ूम इन/आउट, स्क्रीन चौड़ाई में फिट, फुल-स्क्रीन और माउस ड्रैग पैनिंग।
* **✂ अखबार की कतरन (Article Clipping Tool)**: अखबार के किसी भी हिस्से या फोटो को माउस से सेलेक्ट करके PNG इमेज डाउनलोड करने या सीधे व्हाट्सएप पर शेयर करने की सुविधा।
* **अभिलेख व पुराने अंक (Date Archive)**: किसी भी पूर्व तिथि का अखबार कैलेंडर या ड्रॉपडाउन से तुरंत लोड करने की सुविधा।
* **मूल पीडीएफ डाउनलोड**: एक क्लिक में संपूर्ण 8-10 पन्नों का मूल पीडीएफ डाउनलोड।
* **पेज फिल्मस्ट्रिप (Filmstrip)**: नीचे सभी पन्नों के थंबनेल के साथ सहज 1-क्लिक नेविगेशन।

### 3. एडमिन सीएमएस एवं ई-पेपर मैनेजर (`admin.html`)
* **समाचार मास्टर (News CMS)**: सामान्य लेख जोड़ना, संशोधित करना, हटाना और सक्षम/अक्षम करना।
* **📄 समर्पित ई-पेपर मास्टर (E-Paper Manager)**:
  * 100MB तक की दैनिक अखबार पीडीएफ फाइल अपलोड।
  * **⚡ ऑटो-कन्वर्टर**: पीडीएफ से अपने आप सभी पन्नों को अलग-अलग हाई-रेजोल्यूशन जेपीजी इमेजेस में रेंडर करना (`epaper-renderer.js` + WebAssembly/OpenJPEG इंजन)।
  * प्रकाशित अंकों का दिनांकवार प्रबंधन (सक्रिय/निष्क्रिय, प्रीव्यू, डिलीट)।
* **सुरक्षा एवं ऑडिट लॉग्स**: सुरक्षित टोकन ऑथेंटिकेशन और सभी एडमिन गतिविधियों की विस्तृत लॉगिंग।

## 📂 प्रोजेक्ट संरचना (Project Structure)
```
dainik-manyawar/
├── index.html            # मुख्य पृष्ठ (Homepage)
├── category.html         # श्रेणी एवं खोज पृष्ठ
├── article.html          # एकल समाचार वाचक पृष्ठ
├── feed.html             # लाइव समाचार टाइमलाइन
├── epaper.html           # समर्पित ई-पेपर रीडर (कतरन + ज़ूम + आर्काइव)
├── admin.html            # प्रशासक सीएमएस पैनल (समाचार व ई-पेपर मास्टर)
├── login.html            # एडमिन सुरक्षित लॉगिन
├── styles.css            # सम्पूर्ण सीएसएस स्टाइलिंग व रिस्पॉन्सिव ग्रिड
├── app.js                # फ्रंटएंड कंट्रोलर, राउटिंग और यूटिलिटी
├── server.js             # एक्सप्रेस बैकएंड सर्वर और रेस्ट एपीआई
├── epaper-renderer.js    # हाई-फिडेलिटी वेक्टर व जेपीएक्स पीडीएफ कनवर्टर
├── db.json               # मुख्य डेटाबेस (डेटा/स्कीमा)
├── package.json          # एनपीएम डिपेंडेंसी मैनिफेस्ट
└── uploads/              # अपलोडेड मीडिया डायरेक्टरी
    └── epaper/           # ई-पेपर पीडीएफ व रेंडर्ड पन्ने
```

## 🚀 स्थानीय सेटअप व इंस्टॉलेशन (Installation & Setup)

1. **रिपोजिटरी क्लोन करें:**
   ```bash
   git clone https://github.com/kuldepsinghlk85/dainikmanyavar.git
   cd dainikmanyavar
   ```

2. **डिपेंडेंसी इंस्टॉल करें:**
   ```bash
   npm install
   ```

3. **सर्वर प्रारंभ करें:**
   ```bash
   npm start
   ```
   डिफ़ॉल्ट रूप से सर्वर `http://localhost:3000` (या `process.env.PORT`) पर चलेगा।
